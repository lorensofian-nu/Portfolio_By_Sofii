# Fotos del portfolio

Coloca tus imágenes en esta carpeta usando estos nombres exactos:

- `hero.jpg`: imagen principal del inicio.
- `perfil.png`: foto de perfil de la sección Sobre mí.

La imagen de perfil actual está vacía y debe reemplazarse por un archivo PNG real. Si usas otro formato o nombre, actualiza el atributo `src` correspondiente en `index.html`.

Puedes usar `.jpg`, `.png` o `.webp`; si cambias la extensión, actualiza también la ruta en `index.html`.

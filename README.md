# Portfolio de Sofía Núñez

One page responsive para presentar trabajo de diseño digital y desarrollo frontend.

## Ejecutar en local

Como es un sitio estático, basta con servir esta carpeta:

```bash
python3 -m http.server 4173
```

Después abre `http://localhost:4173`.

## Publicar en GitHub Pages

En GitHub, entra a **Settings > Pages**, selecciona **Deploy from a branch**, elige `main` y la carpeta `/ (root)`. El archivo `index.html` será el punto de entrada.
